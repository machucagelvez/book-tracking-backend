# Book Tracking API

1. Clonar el repositorio
2. Instalar las dependencias:

```
npm install
```

3. Clonar el archivo `.env.template` y renombrarlo a `.env`
4. Configurar las variables de entorno
5. Arrancar la BD:

```
docker-compose up -d
```

6. Arrancar la app:

```
npm run start:dev
```
